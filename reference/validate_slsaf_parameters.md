# Validate SLSAF Parameters

Validates an `slsaf_parameters` object, the configuration of the
Simulated Long-Short Allocation Framework.

## Usage

``` r
validate_slsaf_parameters(object)
```

## Arguments

- object:

  An object of class `slsaf_parameters`.

## Value

`TRUE` invisibly if the configuration is valid. Stops with an
informative message otherwise.
