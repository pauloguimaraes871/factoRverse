# Show Risk-Targeting Parameters

Displays the risk-targeting configuration contained in a
`risk_target_parameters` object: the residual sleeve, the target and the
metric it is stated in, the response exponent, where the current risk
estimate comes from, the exposure signal if one is used, and the bounds
on the risky sleeve.

## Usage

``` r
# S4 method for class 'risk_target_parameters'
show(object)
```

## Arguments

- object:

  A `risk_target_parameters` object.

## Value

Invisibly returns NULL.
